Railway Ticket Management System - API Reference
=================================================

1. User Management
==================
Action,Method,Endpoint,Sample JSON Body / Parameters
Login,POST,/api/user/login,"{ ""username"": ""arif"", ""password"": ""pass123"" }"
Register,POST,/api/user,"{ ""username"": ""arif"", ""password"": ""pass123"", ""email"": ""arif@mail.com"", ""fullName"": ""Arif Ahmed"", ""role"": ""USER"" }"
Update,PUT,/api/user,"{ ""id"": 1, ""username"": ""arif"", ""email"": ""arif@mail.com"", ""fullName"": ""Arif Rahman"", ""role"": ""USER"" }"
Get,GET,/api/user/{id},No body. Example: /api/user/1
List,GET,/api/user?page=1&size=10,Query params: page, size
Delete,DELETE,/api/user/{id},No body. Example: /api/user/1
Note: All authenticated endpoints require header: Authorization: Bearer {token}
