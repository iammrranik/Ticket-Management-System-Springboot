Railway Ticket Management System - API Reference (JSON Format)
===============================================================

Authentication:
  All endpoints except Login and Register require header:
    Authorization: Bearer {token}

  Get token from Login response.

1. User Management
==================

Login:
  POST /api/user/login
  {
    "username": "arif",
    "password": "pass123"
  }
  Response: { "token": "eyJ...", "id": 1, "username": "arif",
              "fullName": "Arif Ahmed", "role": "USER" }

Register:
  POST /api/user
  {
    "username": "arif",
    "password": "pass123",
    "email": "arif@mail.com",
    "fullName": "Arif Ahmed",
    "role": "USER"
  }
  Response: void

Update:
  PUT /api/user
  {
    "id": 1,
    "username": "arif",
    "email": "arif@mail.com",
    "fullName": "Arif Rahman",
    "role": "USER"
  }
  Response: void

Get:  GET /api/user/1
  Response: { "id": 1, "username": "arif", "email": "arif@mail.com",
              "fullName": "Arif Ahmed", "role": "USER" }

List: GET /api/user?page=1&size=10
  Response: [ { "id": 1, ... }, { "id": 2, ... } ]

Delete: DELETE /api/user/1  Response: void

===================

  {
    "trainRegistrationNumber": "TRAIN-001",
    "trainName": "Subarna Express",
    "totalCoaches": 12,
    "totalAcCoaches": 4,
    "totalNonAcCoaches": 6,
    "totalCompartmentCoaches": 2
  }

Update:
  PUT /api/train
  {
    "id": 1,

    "trainName": "Subarna Express v2",
    "totalCoaches": 10,
    "totalAcCoaches": 3,
    "totalNonAcCoaches": 5,

Get:     GET /api/train/1
List:    GET /api/train?page=1&size=10
Delete:  DELETE /api/train/1
Find:    GET /api/train/number/TRAIN-001

6. Ticket Booking & Return
==========================

Save:
  POST /api/ticket
  {
    "userId": 1,
    "scheduleId": 1,
    "coachId": 1,
    "seatNumber": "A1",
    "totalAmount": 1200.0
  }

Update:
  PUT /api/ticket
  {
    "id": 1,
    "userId": 1,
    "scheduleId": 1,
    "coachId": 1,
    "seatNumber": "A1",
    "totalAmount": 1200.0,
    "status": "BOOKED"
  }

Get:     GET /api/ticket/1
List:    GET /api/ticket?page=1&size=10
Delete:  DELETE /api/ticket/1
ByUser:  GET /api/ticket/user/1
BySched: GET /api/ticket/schedule/1

Book:
  POST /api/ticket/book
  {
    "userId": 1,
    "scheduleId": 1,
    "coachId": 1,
    "seatNumber": "A1",
    "totalAmount": 1200.0
  }
  Response: { "id": 1, "status": "BOOKED", ... }

Return: POST  /api/ticket/return/1
  Response: { "id": 1, "refundAmount": 1080.0, "status": "RETURNED", ... }

Check: GET /api/ticket/check-seat/1/1/A1
  Response: true

  {
    "trainId": 1,
    "currentStationId": 2,
    "nextStationId": 3,
    "status": "ON_TIME",
    "lastUpdated": "2026-05-20T10:00:00"
  }

  PUT /api/train-status
  {
    "id": 1,
    "trainId": 1,
    "currentStationId": 3,
    "nextStationId": 4,
    "status": "DELAYED",
    "lastUpdated": "2026-05-20T12:00:00"
  }

List:   GET /api/train-status?page=1&size=10
Delete: DELETE /api/train-status/1
ByTrain: GET /api/train-status/train/1

  PUT /api/train-status/location/1/3/4/ON_TIME
