========================================
PART A: PUBLIC ENDPOINTS (No Token)
================================--------

  A1. REGISTER a new user (anik = ADMIN, anika = USER)
  ─────────────────────────────────────────────────────
  POST http://localhost:8080/api/user
  Content-Type: application/json

  → anik (ADMIN):
  {
    "id": 0,
    "username": "anik",
    "password": "anik123",
    "email": "anik@railway.com",
    "fullName": "Anik Admin",
    "role": "ADMIN"
  }

  → anika (USER):
  {
    "id": 0,
    "username": "anika",
    "password": "anika123",
    "email": "anika@example.com",
    "fullName": "Anika User",
    "role": "USER"
  }

  A2. LOGIN (get JWT token)
  ─────────────────────────────────────────────────────
  POST http://localhost:8080/api/user/login
  Content-Type: application/json

  → anik:
  { "username": "anik", "password": "anik123" }

  Response (save this token for ADMIN operations):
  {
    "token": "eyJhbGci...",
    "id": 1,
    "username": "anik",
    "email": "anik@railway.com",
    "fullName": "Anik Admin",
    "role": "ADMIN",
    "createdAt": "2026-05-15T12:00:00"
  }

  → anika:
  { "username": "anika", "password": "anika123" }

  Response (save this token for USER operations):
  {
    "token": "eyJhbGci...",
    "id": 2,
    "username": "anika",
    "email": "anika@example.com",
    "fullName": "Anika User",
    "role": "USER",
    "createdAt": "2026-05-15T12:00:00"
  }

PART B: USER OPERATIONS (anika's Token)
========================================
  Use Authorization: Bearer <anika_token> for all requests below.

  B1. View all stations
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/station?page=1&size=10

  B2. View all trains
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/train?page=1&size=10

  B3. View all schedules
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/schedule?page=1&size=10

  B4. Find schedules by source station (Dhaka = id 1)
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/schedule/source/1

  B5. Find schedules by destination (Chittagong = id 2)
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/schedule/destination/2

  B6. View coaches for Subarna Express (train id = 1)
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/coach/train/1

  B7. Check seat availability (schedule 1, coach 1, seat A1)
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/ticket/check-seat/1/1/A1

  B8. Book a ticket
  ─────────────────────────────────────────────────────
  POST http://localhost:8080/api/ticket/book
  Content-Type: application/json

  {
    "id": 0,
    "userId": 2,
    "scheduleId": 1,
    "coachId": 1,
    "seatNumber": "A1",
    "bookingTime": "2026-05-15T14:00:00",
    "totalAmount": 1200.0,
    "status": "BOOKED"
  }

  Response: Returns the booked Ticket with generated id.

  B9. View all food items
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/food-item?page=1&size=10

  B10. Check food availability (Chicken Biryani, id=1, qty=2)
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/food-item/check-availability/1/2

  B11. Place a food order for ticket id 1
  ─────────────────────────────────────────────────────
  POST http://localhost:8080/api/food-order/place
  Content-Type: application/json

  {
    "id": 0,
    "ticketId": 1,
    "totalAmount": 270.0,
    "orderTimestamp": "2026-05-15T14:30:00",
    "status": "PLACED"
  }

  B12. Return a ticket (id = 1)
  ─────────────────────────────────────────────────────
  POST http://localhost:8080/api/ticket/return/1

  Response: Returns the Ticket with refund_amount calculated per ReturnPolicy.

  B13. View return policies
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/return-policy?page=1&size=10

  B14. View train status for Subarna Express (train id 1)
  ─────────────────────────────────────────────────────
  GET http://localhost:8080/api/train-status/train/1

========================================
PART D: ENDPOINT SUMMARY BY ROLE
========================================

  PUBLIC (no token required):
    POST /api/user               Register new user
    POST /api/user/login         Login, returns JWT

  USER (anika) — any authenticated user can:
    GET  /api/**                 All read/list/find endpoints
    POST /api/ticket/book        Book a ticket
    POST /api/ticket/return/{id} Return a ticket
    POST /api/food-order/place   Place a food order

  ADMIN (anik) — hasRole ADMIN:
    POST/PUT/DELETE /api/user/**         User CRUD
    POST/PUT/DELETE /api/train/**        Train CRUD
    POST/PUT/DELETE /api/coach/**        Coach CRUD
    POST/PUT/DELETE /api/station/**      Station CRUD
    POST/PUT/DELETE /api/schedule/**     Schedule CRUD
    POST/PUT/DELETE /api/food-item/**    FoodItem CRUD
    POST/PUT/DELETE /api/food-order/**   FoodOrder CRUD
    POST/PUT/DELETE /api/food-order-detail/** FoodOrderDetails CRUD
    POST/PUT/DELETE /api/return-policy/** ReturnPolicy CRUD
    POST/PUT/DELETE /api/train-status/** TrainStatus CRUD
    POST/PUT/DELETE /api/ticket/**       Ticket CRUD
    PUT  /api/coach/fare/{id}/{fare}     Update coach fare
    PUT  /api/food-item/quantity/{id}/{qty} Update stock
    PUT  /api/food-order/status/{id}/{status} Update order status
    PUT  /api/schedule/time              Update schedule time
    PUT  /api/train-status/location/{...} Update train location
